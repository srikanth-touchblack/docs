## OverView

Touch Black is a project management platform for film/ad production. Besides reserving shoot studios and equipment, the marketplace allows producers to hire technical talent and actors. Furthermore, it allows for invoicing and payments. Producers will identify talent, book schedules, and pay for the talent on Touch Black. TouchBlack is also working on automating GST and TDS coordination issues for the producer.

## Features
### Device Registration
Device is getting registered first, for that we're making a network call to a backend route (check endpoints.ts). for this we're passing a persistent-uuid which we're saving in the phone

### Auth
Auth consists of login/signup (which're same, meaning if the user's no. exists, the user'd be logged in otherwise a new a/c would be created.)
#### Login
To Login, enter the phone number, accept TNC and enter the otp sent
#### Signup
To Signup, enter the phone number, accept TNC and enter the otp sent
#### Account Selection & different types of accounts
When an account has both Talent & Producer profiles available, we show an account selection screen

> There're 3 types of accounts  
> 1. Talent
> 2. Producer
> 3. Studio

### Navigation
Check `presenters/index.tsx` file and `presenters/TabNavigator` file for navigation.  
Tab navigator is getting changed for each types of profiles.

### Home Screen
Check `presenters/Home.tsx` file for home screen content. It's responsible for Talent and Producer home screen. For Studio, check `presenters/studio` directory

### Blackbook
Check `Blackbook.tsx` file for blackbook, blackbook meaning bookmarkin' a Talent and/or their videos.

### Search
Check `presenters/search/Search.tsx` for search.

### Projects
Check `Projects.tsx` file for projects view for producer.
Check `TalentProjects.tsx` file for projects screen for talent.

### Calendar

#### Talent Calendar
> Check `TalentCalendarView.tsx` for calendar view of the Talent logged in  
> Check `OtherTalentCalendarView.tsx` for calendar view of the other talents  

#### Producer Calendar
> Check `ProducerCalendarView.tsx` for calendar view of the Producer logged in  
> Check `OtherProducerCalendarView.tsx` for calendar view of the other producers  

#### Studio Calendar
> Check `StudioCalendarView.tsx` for calendar view of the Studio logged in  
> Check `OtherStudioCalendarView.tsx` for calendar view of the other studios  

### Messages
Check `presenters/messages` directory for Everything releated to messages

### Notifications
Check `Notifications.tsx` file for notifications

### Profile

#### Talent Profile
In Talent Profile, there's 3 tabs out there alongwith profile picture show and edit functionality

##### Talent Showreels
In Talent Showreels, there's search & filters and list of videos  
Initially we're only displaying list of showreels, and upon search query or filter we're changing the list to searched results from showreels results.

##### Talent Details
Talent can edit his details like name, education, awards, location etc.

##### Other Films
Talent can upload other types of films as well, on which he's worked on but it's not under any Production House. i.e. short films, reels, short videos etc.

#### Producer Profile
In Producer Profile, there's 3 tabs out there alongwith profile picture show and edit functionality

##### Producer Films
In Producer Films, there's search & filters and list of videos  
Initially we're only displaying list of producer films, and upon search query or filter we're changing the list to searched results from films results.

##### Business Info
Producer can edit his details like name, education, awards, location etc.
> **Note**: Only owner of Production house can edit the profile photo, details etc.

##### Team
Team search is implemented locally

#### Studio Profile
It's a separate 3rd type of profile which are studios, Production house can book such studios and thus Production house and their team members and the Studio and their team members can have a chat for a project/booking

### Profile Share
Deep linking is setup for profile sharing, enabling talent and producer profiles to be shared

### Deep Linking
For more info on deep linking, check `App.tsx` file & `AndroidManifest.xml` file for Android.
For more info on deep linking, check `App.tsx` file & `Info.plist` file for iOS.

## App Architecture  
Custom Hook-based Architecture with React Query. It combines the following principles:

    - Custom Hooks with React Query: For network calls and caching.  
    - State Management with Context API and Local States: Leveraging Context for app-wide state and local state for more granular control.  
    - Design System and Icon System: Organized as separate reusable packages to maintain consistency across the app.  

This architecture reflects a modular, scalable, and maintainable approach, where the backend is treated as the source of truth and network caching is used to decrease the load on the server.

## Deployment

### Android
0. Go to https://play.google.com/console/u/3/developers/6872250137193235204/app-list
1. Create a production release
2. Click on the 'Upload bundle' button and upload the generated bundle
3. Modify the version name
4. Add release notes
5. Submit the release for review
6. If Managed publishing is on, then push the updates live upon successful review

### iOS
0. Go to https://appstoreconnect.apple.com/apps/6504214097/distribution/ios/version/deliverable
1. Create a production release
2. Select the appropriate build
3. Add release notes
4. Submit the release for review
5. If Managed publishing is on, then push the updates live upon successful review
